# Emby Bridge · 播放器配置互转

把各播放器之间的服务器配置备份，做成一个**纯前端、零后端、跨平台**的互转工具。在 Mac、iPhone、安卓、平板或任意浏览器里，把一种播放器的配置备份转换成另一种，不用再对着 Emby 服务器手工重录账号。

> ⚠️ **实验性工具，不保证所有播放器 / 版本 / 来源的备份都通用。** 请保留原始备份，导出后先在目标 App 里验证，确认可用再替换旧配置。

👉 在线使用：**https://plannm.github.io/emby-bridge/** ｜ 或打开根目录的 **`index.html`**（单文件，双击即可，完全离线）。

---

## 它能做什么

1. **导入**：拖入任意一种播放器导出的配置备份；自动识别格式并解密，列出所有服务器。
2. **编辑**：修改名称、地址、账号、密码、User ID、Token、图标、备用线路；用单选项明确当前活动线路。支持批量粘贴、CSV、保守去重、搜索、分页和勾选导出范围。
3. **导出**：先检查范围、字段损失及风险，再在本地生成目标文件。默认仅迁移已勾选服务器；完整原生备份需要同源、同格式、全量服务器。

导入有文件级进度和取消保护；清空只影响页面内存，不删除原文件。卡片按需展开，每页最多 50 台；键盘可操作弹窗和线路，动效遵循系统“减少动画”设置。文件上限为 20 MiB，最多 5,000 台服务器。

| 播放器 | 文件 | 支持 |
| --- | --- | --- |
| Hills | `.json` | 读 / 写 |
| AfuseKt | `.json` | 读 / 写（明文，不含 User ID / Token） |
| Yamby / Tsukimi CommonConfig | `.json` | 读 / 写 |
| CapyPlayer | `.json` | 读 / 写 |
| LinPlayer | `.lpbak` | 读 / 写 |
| WWPlayer 电脑端 | `.wwpcfg` | 读 / 写（V1 便携配置） |
| WWPlayer 手机端 | `.json` | 读 / 写（schemaVersion 2 便携备份，不迁移密码 / Token） |
| AI Player | `.json` | 读 / 写 |
| 通用中间格式 / CSV | `.json` / `.csv` | 读 / 写（明文，便于长期保存与批量编辑） |

原有样本验证之外，离线自检覆盖 8 种播放器格式及 8×9 跨格式生成，并检查多行凭据、URL、活动线路、原生标识和导出范围。**这只证明格式层的测试结果，不代表所有目标 App 或版本均能导入**。

## 导出范围与批量编辑

- **仅服务器迁移（默认）**：导出已勾选服务器及其原生服务器字段，不带整份文档的设置、历史或副表。搜索仅影响可见列表，不改变勾选范围。
- **完整原生备份**：显式选择后，仅允许一份同格式来源的全部服务器；删减、合并多来源、去重或新增后不能使用此模式，避免隐藏的历史或设置引用越界。Hills v3 暂不支持完整导出，只可迁移服务器为 v2。
- **CSV**：线路列改用 JSON 数组，旧的 `名称=地址|名称=地址` 仍可读取，但存在歧义时会报错。含逗号、双引号、LF / CRLF 的字段可无损往返；页面将含换行字段显示为只读的转义预览，原值继续按原样导出，需修改时请通过 CSV / JSON，避免单行输入框删除换行。表格软件中的公式风险会在导出前提示，不会通过加前缀修改密码。
- **快捷文本**：支持一行一个 URL，或 `名称 | 地址 | 用户名 | 密码`。含分隔符的字段请用双引号包围，双引号本身写成 `""`；多余字段不再被静默丢弃。
- **URL**：保留路径、查询、内嵌凭据的大小写和尾部斜杠。CapyPlayer 无法表达查询参数、片段、内嵌凭据或端口 0，或地址含不完整 scheme、反斜杠 / 原始控制字符时，导出会明确拒绝，而非静默修正；原生协议 / 主机 / 默认端口规范化会提示。
- **通用 JSON v2**：保留稳定线路标识和服务器原生扩展，但不保存整份备份上下文。仍可读取旧 v1；需要完整原生备份时，请保留原始文件。

## WWPlayer Android 手机端

本次离线静态核对了官方 **0.4.9 / versionCode 593** 的 `schemaVersion: 2` 便携备份：

- 可以迁移 `userName` / `userId`，但 `PortableServerProfile` **没有密码 / Token 字段**。
- `credentialsIncluded: true` 会被原生校验器拒绝；在 `false` 下增加 `password` / `accessToken` 会被忽略，不能用它们恢复登录。
- 输出始终为 `credentialsIncluded: false`、`requiresAuthentication: true`，仅保留已核对的可移植服务器 / 线路字段；导入后需要重新认证，不提供无效的“包含密码”开关。
- 导出前检查非空名称、兼容标识与线路地址，拒绝内嵌账号、片段及疑似认证查询参数。不自动删改 URL；无效 / 重复原生标识仅在服务器迁移模式修复，完整模式拒绝更换引用。

以上是官方包的静态格式证据，**不是目标 App 的运行验收**，也不代表其它版本或内部云快照均采用相同契约。此前导入失败还可能来自标识、地址、必需字段或附属数据结构；仅增加密码字段不能单独解释失败。详细版本与验证边界见 `docs/FORMATS.md`。

## 已知限制

本工具**不保证所有播放器、所有版本、所有来源的备份都通用**。备份格式来自对有限样本的兼容实现，客户端更新或换一个导出来源就可能解析失败；跨格式转换主要迁移服务器地址、账号与线路，播放器特有的设置不保证保留。请保留原始备份，导出后先在目标播放器里验证，确认可用再替换旧配置。（具体格式差异见 `docs/FORMATS.md`。）

## 隐私与安全（重要）

- **绝不联网**：页面通过 CSP 把 `connect-src` 设为 `none`，禁掉 fetch / XHR / WebSocket / Beacon；没有外部脚本、字体、图片、统计代码。所有加解密用浏览器内置的 Web Crypto 在本地完成。
- **绝不登录服务器**：工具只读写备份文件，不会向任何 Emby / Jellyfin 地址发起请求，也不会拿账号密码去试登录，因此不会触发服务器的风控或封号。
- **不落盘**：不写 `localStorage`、Cookie、IndexedDB；刷新页面即清空。
- **备份即凭据**：导出文件里包含账号、密码与访问令牌（或等价的可逆数据）。请当作密码文件保管，**不要提交到公开仓库、不要传网盘分享链接、不要发给别人**。仓库的 `.gitignore` 已排除常见备份文件名。

> 本工具仅用于迁移你本人有权使用的播放器配置，与各播放器官方均无关联。

## 使用流程示例

1. 在任意支持导出配置备份的播放器里，导出一份服务器配置备份（`.json` / `.lpbak` / `.wwpcfg` 等）。
2. 把文件传到 Mac / 手机，打开本网页，拖进「导入备份」。
3. 检查列表，必要时批量粘贴补齐几十台服务器、去重。
4. 点目标播放器导出卡片，检查导出模式、勾选范围及风险并确认 → 得到 `.json` / `.lpbak` / `.wwpcfg` → 在目标 App 里「导入配置」。

建议同时导出一份「通用中间格式」自己留档：它是明文 JSON，以后在任何设备上打开本网页导入它，就能再转成任意播放器格式。
