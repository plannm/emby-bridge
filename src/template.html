    ⚠ 已知限制

    本工具不保证所有播放器通用。不同版本、不同来源的备份可能解析失败或丢失部分设置。请保留原始备份，导出后先在目标 App 里验证再用。

    它到底做什么？安全吗？

    它只做一件事：把你已有的播放器备份文件读进来，转换成另一种播放器认识的备份文件写出去。全部加解密都在你的浏览器里完成，页面通过 CSP 把 connect-src 设为 none，从浏览器层面禁掉了 fetch / XHR / WebSocket 等一切外联，因此绝不会去访问或登录你的 Emby 服务器，也就不存在触发服务器风控、封号的问题。页面不引用任何外部 CDN 资源，可离线使用。

    典型用法：导出一份备份 → 在任意设备上转换

    ① 在任意支持「导出服务器配置 / 备份」的播放器里导出一份文件（.json / .lpbak / .wwpcfg 等）。
    ② 把这个文件传到 Mac / 手机（AirDrop、微信文件传输、网盘均可），在本网页「导入备份」里打开。
    ③ 检查、修改、去重，然后点目标播放器对应的导出按钮，把下载下来的文件交给目标 App 的「导入配置」即可。
    也可以先导出「通用中间格式」长期保存；下次打开网页直接导入它，再转成任意播放器格式。

    批量添加支持哪些写法？

    点「批量粘贴 / CSV」，支持三种：
    · CSV：表头为 name,type,url,username,password,userId,accessToken,icon,lines,serverName,remark,activeLine（可只写其中几列）。线路列使用 JSON 数组，保留名称、地址和活动标记；旧 名称=地址|名称=地址 仍可读取，但分隔符有歧义时会报错。含逗号、双引号或换行的字段请按 CSV 规则引用；
    · 每行一台：名称 | https://地址 | 用户名 | 密码，分隔符也可用逗号、分号或制表符；只写 URL 也可以。包含分隔符的字段请用双引号包住，字段内的双引号写作 ""；引号或列数有误会报告失败，不会静默丢弃；
    · 通用中间格式 JSON：本工具自己导出的文件。

    备份文件要怎么保管？

    导出的备份里含账号、密码与令牌（或等价的可逆数据），请当密码文件保管，不要上传到公开仓库、网盘分享链接或陌生网页。

    免责声明：本工具仅用于迁移你本人有权使用的播放器配置。请不要用它处理他人的凭据，也不要把含密码的备份文件提交到公开仓库或发送给第三方。本工具与各播放器官方均无关联。
